# Contributing

This repository is a personal learning project. The goals are to explore Next.js, TypeScript, and scraping architecture while keeping changes safe and easy to review.

## Workflow

- Create a new branch for each experiment or feature.
- Work in small increments.
- Use clear commit messages describing what you learned and what changed.
- Run `npm run dev` or `npm run build` before pushing.
- Keep the main branch stable and only push working code.

## Branch naming

Use meaningful branch names such as:

- `feature/search-filter`
- `experiment/indeed-scraper`
- `fix/ts-config`

## Testing

Before pushing changes:

- `npm run dev`
- `npm run build`
- `npm run typecheck`

## Issues and experiments

Use GitHub issues to track ideas, bugs, and experiments. The issue templates are there to help you capture what you try and what you learn.
